# 첫 실행 설정

이 패키지는 Codex 스킬이다. Aside 확장 프로그램, 로그인, Notion 권한을 설치하거나 우회하는 프로그램이 아니다. 실행 환경이 해당 도구를 제공해야 실제 조회·발송이 가능하다.

## 1. 계정과 작업 위치

사용자에게 아래 네 가지를 한 번에 받는다. 이미 프로젝트 문서나 현재 연결에서 확인할 수 있으면 다시 묻지 않는다.

- 발신 Instagram ID
- 담당자명 (확정 문구 기본값: 김하늘)
- Notion 인플루언서 DB URL
- Notion 일자별 메가셀러 리스트 URL

스크립트 안내: 스킬 폴더에서 `python3 scripts/setup.py` 실행. 설정은 `.local/config.json`에 저장된다. 비밀번호·쿠키·토큰·수신자 정보는 입력받지 않는다. 스크립트로 설정하기 어려우면 대화로 받은 같은 필드를 비공개 설정 파일에 저장한다.

기본 브랜드는 위시어다. 다른 브랜드는 이 패키지의 수치·매출 사례를 전용하지 않도록 새로운 확정 문구를 먼저 받는다. 설정의 `screen_mode` 기본값은 `no-disruption`이며 창 활성화·화면/마우스 조작을 금지한다. 사용자에게 기존 화면 제한이 있으면 설정으로 덮어쓰지 않는다.

## 2. Aside 연결

현재 호스트에서 제공하는 브라우저/앱 도구의 문서와 연결 목록을 확인한다. Aside가 백그라운드 제어 가능한 브라우저로 연결돼 있으면 그 문서의 방법으로 계정과 DM을 읽는다.

연결이 없으면 사용자가 사용할 호스트의 실제 지원 연결 방법을 먼저 확인한다. 도구가 제공하지 않는 설정 메뉴·확장 설치 링크·디버깅 포트·Aside API를 지어내지 않는다. 앱이 실행돼 있다는 사실과 백그라운드 제어가 가능하다는 사실은 다르다.

앱 화면 읽기만 가능한 환경에서는 현재 화면 관찰까지만 한다. 금지된 화면 조작이 필요하면 정확히 필요한 단계와 이유를 알린다. 사용자가 허용하지 않으면 발송하지 않고 `연결 필요`로 종료한다. 사용자가 DM창을 직접 열어도 검색·대화 이동까지 자동 가능해지는 것은 아니므로 실제 지원 범위를 다시 확인한다.

로그인은 사용자가 Aside에서 직접 완료하고, 실제 발신 ID를 설정과 대조한다. 다른 계정이면 보내지 않는다. 사용자의 Chrome으로 대신 로그인하지 않는다.

## 3. Notion 연결

사용자가 사용하는 호스트의 Notion 커넥터를 연결하고 지정한 DB·일자 리스트 접근 권한을 확인한다. URL을 알고 있어도 권한이 보장되지는 않는다. 스키마를 API로 읽어 실제 속성명을 확인한다. 브라우저로 우회하지 않는다.

## 4. 실행 준비 보고

발신 계정, Aside 조회/발송 가능 여부, 화면 제한, Notion 읽기/쓰기 가능 여부, 확정 문구를 짧게 보고한다. 첫 연결 점검에서 테스트 DM은 보내지 않는다. 이후 사용자의 실제 요청 범위에서 실행한다.

예시 요청:
- `$mega-seller-dm 처음 설정해줘`
- `$mega-seller-dm 메가셀러 중 실제 DM 미컨택인 사람만 확인해줘. 발송하지 마.`
- `$mega-seller-dm 방금 확인한 미컨택 명단에 확정 문구로 보내고 Notion에 기록해줘.`
