# 상품·수량과 출고 집계

## 이 업무에서 확정한 기본값

- 단일 희망 맛만 있고 수량이 없으면 그 맛 1박스로 접수한다. 사용자가 준 명시 수량·단위가 우선한다.
- 상품 미지정 배송 정보의 기본 상품은 `맛별 박스`, 수량 1이다. `맛별 박스`는 기존 발주서의 상품명이며 집계에서 상품 수량 1박스로 취급한다. 임의로 네 상품 행으로 펼치지 않는다.
- `맛별 N박스씩`은 마카다미아초코·피스타치오초코·버터쿠키·시나몬토스트를 각 N박스씩, 총 4N박스로 기록한다. 실제 SKU 구성이 변경되면 사용자나 최신 상품 원본으로 확인한다.
- 단일 맛 박스는 원본 상품명을 유지한다. 신규 원문이 맛 이름뿐이면 `<맛> 박스`로 작성한다. 첨부 파일의 `마카다미아 박스`를 임의로 다른 상품명으로 변경하지 않는다.
- 명시된 낱개는 `위시어 프로틴바 낱개`로 표준화하고 맛을 별도 `flavor`와 `메모`에 보존한다. 예: `시나몬토스트 낱개 / 파손 재출고`.
- `랜덤 박스`는 원본·사용자에게 명시된 경우에만 사용한다. 이벤트라는 이유로 랜덤 상품을 추정하지 않는다.

## 추가와 변경의 예

- 기존 버터쿠키 1박스에 시나몬토스트 1박스 `추가` → 두 상품 각 1박스, 총 2박스.
- 기존 맛별 2박스씩에서 맛별 3박스씩으로 `변경` → 네 상품 각 3박스, 총 12박스. 기존 8박스에 12박스를 더하지 않는다.
- 같은 사람에게 낱개 맛 3종 → 맛별 행을 유지한다. 표준 상품명이 같다는 이유로 두 행을 없애지 않는다.

## 수령자·행·물량

- 수령자 키는 이름 + 숫자만 남긴 전화번호 + 확인된 주소다. 단순 주소 띄어쓰기 차이는 비교용으로 정규화할 수 있으나 출력 주소는 원문을 보존한다.
- 주소 변경, 별도 건물·호수는 별도 배송이 될 수 있다. 다른 주소를 이름·전화번호만으로 같은 배송으로 합치지 않는다.
- 같은 주소의 표현만 달라진 것이 사용자 확인으로 확정된 경우 하나의 주소로 출력하거나 명시적 `recipient_group`을 기록한다.
- 박스 합계와 낱개 합계를 분리한다. 세트 구성 내부 수량을 발주서 상품 수량으로 바꾸지 않는다.
- 이벤트·CS·메가셀러 등 출고 유형은 동일 시트의 메모로 구분한다. 이벤트 인원은 일반 시딩 인원에서 제외하되 전체 출고 수령자 수에는 포함한다.
