# 새 팀원 첫 설정

현재 프로젝트와 사용자 요청에서 아래를 확인하고 빠진 항목만 한 번에 받는다.

- 브랜드·실제 발신 담당자명·업무 Instagram ID
- 캠페인 유형, 현재 대상 조건·목표 인원·실행 범위
- Notion 인플루언서 DB URL, 기존 컨택·제외 이력 위치
- 최신 신규 컨택·협업 가이드 원문 위치, 실제 업로드 일정
- 비공개 실행 기록 폴더, 현재 환경이 제공하는 대화 조회·브라우저 도구

설정은 프로젝트의 비공개 위치 또는 스킬의 `.local/config.json`에 보관한다. 비밀번호·쿠키·토큰·수령정보는 이 설정에 넣지 않는다. 과거 계정과 담당자명은 이번 발신자 확인을 대체하지 않는다.

Python 보조 스크립트는 Python 3.9 이상 표준 라이브러리만 사용한다. 설치된 스킬 폴더에서 실행한다. Python이 없는 환경에서는 AI가 승인 문구를 직접 읽어 같은 이름·일정 자리만 치환할 수 있다.

```text
python3 scripts/seeding_tools.py render contact --name 크리에이터명 --contact-name 담당자명
python3 scripts/seeding_tools.py render address --name 크리에이터명 --upload-schedule '실제로 합의한 업로드 일정 문구'
```

호칭이 불명확하면 `--name`을 생략한다. 가이드 인사말은 릴스 제작 가능 회신과 배송정보가 확인된 경우에만 사용한다. 조건 문의가 남아 있으면 CS 초안부터 처리하고 가이드 전달·출고를 보류한다.

최신 프로젝트 원문이 패키지보다 우선한다. 패키지 문구의 제품 수치·성과·광고 표기·음원 안내는 승인된 업무 문구이며 독립 검증된 법률·플랫폼 정책 안내가 아니다. 실제 실행 전 최신 승인 가이드와 다르면 담당자에게 확인하고 임의로 단정하지 않는다.

연결이 없으면 제공된 대화·자료로 초안까지 작성하고 필요한 연결을 알린다. 화면 자동 제어·로그인·Notion 연결은 이 스킬이 설치하지 않는다. 최초 설치 점검에서는 메시지를 보내거나 자동 발송을 활성화하지 않는다.
