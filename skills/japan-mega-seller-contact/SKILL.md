# 일본 메가셀러 컨택

## 처음 설정

현재 요청과 프로젝트 지침에서 발신 브랜드·담당자의 일본어 표기, 대상 계정, 사용할 채널, 기존 컨택 원장과 Notion 기록 위치를 확인한다. 이미 확인한 정보는 다시 묻지 않는다. 원문은 위시어 일본 진출 제안용이며 다른 브랜드에 전용하지 않는다.

스킬 설치는 로그인·브라우저 연결·Notion 접근·발송 승인을 부여하지 않는다. 설정·조회·초안 요청은 실제 발송 권한이 아니다. 화면 조작은 사용자의 허용 범위와 현재 도구 안내를 따른다.

## 초안

1. [assets/contact-ja.txt](assets/contact-ja.txt)를 읽는다. 기존 사용자 제공 일본어 문구에서 이름 두 항목만 변수화한 원문이다.
2. `[크리에이터명]`에는 확인된 활동명 또는 사용자가 지정한 호칭을 넣는다. 이미 `様`가 붙어 있으므로 중복하지 않는다. 계정 ID에서 실명을 추정하지 않는다.
3. `[담당자명]`에는 확인된 담당자의 일본어 표기를 넣는다. 원본 담당자 표기는 `ソンフン`이었으며 다른 팀원에게 자동 적용하지 않는다.
4. 문장·이모지·수치·순서는 이름 외에 임의로 바꾸지 않는다. 전체 초안을 제공한다. 복사 요청은 text 코드블록으로 제공한다.

원문의 영양 수치·판매 실적·순위·협업 사례·일본 진출 상황은 과거 사용자 제공 영업 문구다. 현재 사실로 독립 검증된 데이터가 아니다. 재사용 전 담당자의 최신 확정 문구 또는 근거로 유효성을 확인하고, 미확인이면 초안 밖에 표시하며 실제 발송을 보류한다. 새 성과·건강 효능·보장 표현을 추가하지 않는다.

## 발송 요청이 있는 경우

- 정확한 발신 계정·수신자·현재 요청의 승인 대상과 문구를 확인한다. 기존 대화와 다른 채널의 컨택 원장을 대조하고, 조회하지 못한 대상을 미컨택으로 확정하지 않는다.
- 현재 채널이 Meta 마케팅허브로 지정됐으면 일반 Instagram DM·이메일로 대체하지 않는다. 지원되는 도구와 실제 메시지 권한이 없으면 초안과 연결 필요 사항까지 처리한다.
- 발송 직전 신규 회신·사람의 답변·기존 발송을 다시 확인한다. 입력 본문과 수신자가 일치하는지 대조한다.
- 실제 발신 메시지·외부 메시지 ID 등 완료 근거가 있을 때만 발송 완료로 기록한다. 결과 불명확이면 재발송하지 않고 기존 대화를 먼저 확인한다.
- 경고·활동 제한·로그인·인증 요구 시 해당 발송을 중단한다. 제한을 우회하거나 안전한 간격·건수를 보장하지 않는다.

## 회신과 기록

무료 제품 체험 제안과 공동구매 확정을 구분한다. 수수료·일정·판매 조건을 임의로 합의하지 않는다. 국내 무가 릴스의 제작 의무·수량·광고 활용 조건을 일본 공동구매 제안에 섞지 않는다.

설정·실제 계정·명단·주소·대화·발송 로그는 비공개 작업 폴더에 보관한다. 공유 스킬에는 넣지 않는다. Notion은 지정된 DB의 실제 속성을 확인한 뒤 요청 범위만 기록하고 결과를 재조회한다.
